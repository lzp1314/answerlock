# 答题锁

> 当前版本 **v1.7**　·　支持 Android 5.0+ 的手机、平板、智能电视

电视、手机、平板通用的自律小工具：**前台应用累计使用满设定时长，自动全屏弹出一道语数英题目，
答对才能继续，答错自动换下一题，直到答对为止。**

题库按人教版 1–6 年级编排：数学当场生成、不限题量；语文、英语为内置题库。
年级、科目、答题间隔都可以在设置里自行选择。

---

## 判定规则（先看这条）

除了系统界面（设置、通知栏、安装器、输入法、锁屏），**任何应用在前台都算使用时间** ——
抖音、快手、B 站、腾讯视频、QQ 浏览器、淘宝、拼多多，以及你还没见过的新 App，一律计入。
没有"娱乐应用名单"这种东西，也不检测画面在播什么。

桌面上停留同样计时（按实际使用时间算），挂机在桌面也会累积。

## 一、支持哪些设备

只要是 Android 底层就能装，电视和手机是同一套逻辑，区别只在授权方式。

| 设备 | 系统 | 支持情况 | 授权方式 |
|---|---|---|---|
| 雷鸟 / TCL 电视 | Android TV | 支持 | 需电脑 adb |
| 小米 / 米家电视 | Android（PatchWall） | 支持 | 设置里有「无障碍」入口 |
| 创维 / 酷开电视 | Android 底层 | 支持 | 需电脑 adb |
| 海信 / 聚好看电视 | 多数为 Android 底层 | 多数支持 | 需电脑 adb |
| 索尼电视 | Android TV / Google TV | 支持 | 设置里有「无障碍」入口 |
| 华为智慧屏 | HarmonyOS | 看型号 | 鸿蒙 2/3 有兼容层，鸿蒙 NEXT 不支持 |
| 安卓手机 / 平板 | Android 5.0+ | 支持 | 设置里有「无障碍」入口 |

最低支持 Android 5.0。

### 界面尺寸自适应（32–100 寸）

字号与留白按屏幕可用画布高度分四档，装在哪台机器上都会自动挑一档，不需要手动调。
题干另有一层自动缩字：遇到特别长的题目会按实测宽度逐级缩小字号，保证最多 4 行装得下、不顶出屏幕。

| 档位 | 典型设备 | 题干字号 |
|---|---|---|
| 手机档 | 手机竖屏、小屏平板 | 21sp |
| 电视标准档 | 1080p 电视（40–65 寸） | 26sp |
| 电视大画布档 | 720p 小电视（32–43 寸） | 36sp |
| 超大画布档 | 4K 电视（75–100 寸） | 50sp |

遥控器操作：方向键选到按钮，按「OK / 确定」生效，选中的那一档前面带 ✓。

## 二、安装

### 手机 / 平板

1. 把安装包传到手机（微信、QQ 传文件，或数据线拷贝）
2. 点开安装，提示「禁止安装未知来源应用」时允许一次
3. 桌面出现「答题锁」图标（黄底电视机图标）

### 电视：U 盘方式（不用电脑）

1. 安装包拷到 U 盘根目录
2. U 盘插到电视，打开电视自带的「媒体中心 / 文件管理」
3. 找到安装包点击安装
4. 若提示「禁止安装未知来源应用」，去 **设置 → 安全 → 允许安装未知来源应用**，给文件管理器开权限

### 电视：adb 方式

```bash
adb connect 192.168.x.x:5555      # 电视 IP，需在同一局域网
adb install -r answerlock-v1.7.apk
```

覆盖安装即可，**不用先卸载**，密码与各项设置都会保留。

## 三、必做授权（不做的话锁完全不生效）

### 1. 打开无障碍服务

**答题锁图标 → 输密码（默认 `0000`）→ 点「无障碍设置」→ 在列表里找到「答题锁」并打开。**

跳不进系统页面的，按品牌路径手动进：

| 品牌 | 路径 |
|---|---|
| 小米 / 红米 | 设置 → 更多设置 → 无障碍 → 已下载的服务 |
| 华为 / 荣耀 | 设置 → 辅助功能 → 无障碍 |
| OPPO / 一加 / realme | 设置 → 系统设置 → 无障碍 |
| vivo / iQOO | 设置 → 快捷与辅助 → 无障碍 |
| 三星 | 设置 → 辅助功能 → 已安装的服务 |
| 原生 / Pixel | 设置 → 无障碍 |

**电视用 adb 授权**（遥控器跳不进无障碍页时）：先在「设置 → 关于本机」连点版本号 7 次打开开发者选项，
开启「USB 调试」和「网络调试」，记下电视 IP。

```bash
adb connect 192.168.x.x:5555
adb devices                                     # 出现 device 即连通
adb shell settings put secure enabled_accessibility_services com.family.answerlock/com.family.answerlock.DetectService
adb shell settings put secure accessibility_enabled 1
```

不用重启，打开任意 App 就开始计时。验证：

```bash
adb shell settings get secure enabled_accessibility_services
```

返回内容里带 `com.family.answerlock` 即为成功。

> 如果电视上还开着别的无障碍服务（投屏助手、语音助手等），上面第一条命令会把它们顶掉。
> 想保留就用冒号把原服务拼在前面：
> `adb shell settings put secure enabled_accessibility_services 原服务:com.family.answerlock/com.family.answerlock.DetectService`

### 2. 使用情况访问（手机上强烈建议）

**答题锁 → 输密码 → 点「使用情况权限」→ 找到「答题锁」→ 打开「允许访问使用记录」。**

部分国产系统会限制无障碍读取窗口内容，开了这项，即使无障碍被限制也能正常识别前台应用。

### 3. 后台弹窗与电池白名单（漏了就"时间到了什么都不发生"）

1. **允许后台弹出界面**
   小米：应用管理 → 答题锁 → 其他权限 → 后台弹出界面 → 允许
   OPPO / vivo：应用管理 → 答题锁 → 权限 → 后台弹出界面 / 悬浮窗 → 允许
2. **电池优化加入白名单**
   设置 → 电池 → 应用耗电管理 → 答题锁 → 允许后台活动（无限制）
3. 顺手打开「自启动」

### 4. 从旧版升级时的注意

早期版本改过无障碍服务的配置，系统会缓存旧配置。**升级后请把「答题锁」的无障碍开关
关掉、退出、再进来打开一次**，否则可能仍然是旧行为，照样不计时。

## 四、v1.7 新增：让无障碍不再被系统关掉

这是最容易踩的坑：**用得好好的，退出一次答题锁、或者从最近任务里划掉、清理一次后台，
再进去发现无障碍开关自己变成关的了 —— 锁等于不存在。**

原因不在答题锁：国产系统在「划掉应用 / 一键清理 / 强行停止」之后，会把已经打开的无障碍服务
直接置为关闭，这是系统行为。电视固件也有类似动作（待机唤醒、后台清理、应用冻结），概率比手机低。

v1.7 为此做了三道防线：

| 防线 | 作用 | 需要做什么 |
|---|---|---|
| 后台守护 | 常驻后台，被划掉或清理后自动回来，无障碍跟着恢复 | 默认开启，设置页显示「守护已开」 |
| 无障碍自愈 | 每 15 秒自检一次，发现开关被关掉就直接写回去 | 需要 adb 授权一次（见下） |
| 开机自恢复 | 开机、覆盖安装后自动拉起守护并检修 | 无需操作 |

### 开启自愈（建议做一次，永久有效）

设置页点「开启自愈」，按弹窗提示用电脑执行：

```bash
adb shell pm grant com.family.answerlock android.permission.WRITE_SECURE_SETTINGS
```

- 手机：数据线连电脑，打开「USB 调试」
- 电视：同一局域网 `adb connect 电视IP:5555`

执行后没有任何输出就是成功了，回到设置页会显示「自愈已授权」。此后系统再关无障碍，会被自动写回，
设置页会显示「已自动恢复 N 次」。

### 没有电脑 / 不想开 adb

也能用，只是每次被系统关掉之后要手动进系统设置点一次开关。降低被关概率的做法：
把答题锁加入自启动允许、电池优化「无限制」、后台弹出界面允许，并在最近任务里锁定该应用。

## 五、家长设置

打开「答题锁」→ 输密码，**默认 `0000`，进去第一件事请改成自己的**。

| 设置项 | 说明 |
|---|---|
| 孩子年级 | 1–6 年级，决定题目难度 |
| 出题科目 | 语文 / 数学 / 英语，可多选，至少保留一科 |
| 答题间隔 | 5 / 10 / 15 / 20 分钟，默认 10 分钟 |
| 改密码 | 先验证原密码，再设新密码，最后确认一次 |
| 防卸载 | 开启后不能直接卸载 |
| 重置计时 | 手动把已看时长归零 |
| 无障碍设置 | 跳转系统无障碍页面 |
| 使用情况权限 | 跳转使用记录授权页面 |
| 立即测试 | 不用等时长，直接弹一道题看效果 |
| 结束无限观看 | 提前结束家长买断的那一次 |
| 检查更新 | 手动检查新版本 |
| 守护 / 自愈 | v1.7 新增，见上一节 |

页面顶部常显一行状态：`本机 v1.7 · 线上 v1.7 · 守护运行中`。

下面那块状态信息每 2 秒刷新，是排查「为什么不计时」的第一现场：

```
监控运行中 · 已看 3:42 / 满 5 分钟出题
前台：tv.danmaku.bili  计时中
通道：事件✓ 窗口✓ 使用记录✓
```

- **已看 3:42**：精确到秒，能看出数字有没有在涨
- **前台**：当前判定到的应用包名，后面跟「计时中 / 不计时」
- **通道**：三条识别通道各自是否可用，`✓` 可用、`×` 不可用
- 再往下是最近 10 次前台切换记录，带时间和是否计时

想立刻确认效果，点「立即测试」会直接弹题，不用等时长。

## 六、答题界面：孩子按不出去，家长有两个出口

答题界面底部两个按钮，都要输 4 位家长密码：

| 按钮 | 作用 | 适用场景 |
|---|---|---|
| **家长无限观看** | 这一次不再出题 | 家长自己要看一部电影、追剧 |
| **家长退出** | 关掉这一次，并把已看时长归零 | 孩子已经答过题，或需要临时关掉 |

孩子可能做的动作与结果：

| 动作 | 结果 |
|---|---|
| 按返回键 | 无效（按键被拦截） |
| 按菜单键 / 设置键 / 语音键 | 无效 |
| 按 HOME 回桌面 | 能回，但约 1.2 秒后界面被拉回 |
| 电视关机再开机 | 已看时长存在本地，开机后照样出题（30 分钟内算同一次观看） |
| 手机锁屏后解锁 | 界面盖在锁屏上，解锁后仍在 |
| 长按电源 / 断网 | 与关机同理，恢复后继续锁 |

### 「家长无限观看」的规矩

- 输对密码 → 本次不再计时、不再出题，可以连续看完
- **关电视 / 手机锁屏 / 关机重启 → 立即作废**，下次亮屏从 0 重新计时，到点照样出题
- 它只买「这一次」，买不了「一整天」；孩子拿不到密码，这个按钮对他等于不存在
- 设置页会显示「家长无限制观看中」，也可用「结束无限观看」手动提前结束

**家长退出**输对密码后直接退出，同时把已看时长归零，不会刚退出又弹一道。

### 密码防爆破

连错 5 次开始冷却，第一次 30 秒，之后逐次翻倍（60 秒、120 秒…），最长 5 分钟。
冷却状态保存在本地，关掉弹窗重开也仍在倒计时 —— 否则孩子坐着慢慢试，一小时足够试完一万种。

> 副作用提前知悉：如果故意输错把密码试爆，接下来 5 分钟内他也退不出去，只能重启设备；
> 重启后仍然是锁着的，对他没有好处。

### 改密码

点「改密码」是三步：

1. 输入当前密码 —— 输错会提示并停在这一步
2. 设置新的 4 位密码 —— 与原密码相同会被拒绝
3. 再输一次新密码确认 —— 两次不一致不生效

### 忘了密码

密码存在应用私有数据里，清掉数据等于恢复出厂。手机上：设置 → 应用管理 → 答题锁 → 存储 → 清除数据。
也可以用 adb：

```bash
adb shell pm clear com.family.answerlock
```

清完密码回到 `0000`，但**年级、科目、间隔也会一起归零**，需要重新设置。
无障碍授权通常还在；若发现不锁了，按第三节重新授权一次。

## 七、检查更新

App 启动时会自动比对线上版本，设置页也有「检查更新」按钮。

手动点「检查更新」后一定会弹窗，三种结果都说清楚：

- **已是最新版本**：显示本机版本与线上版本，两个数字对得上才算真的连通
- **发现新版本**：显示更新说明，点「去下载」用浏览器打开安装包地址
- **检查更新失败**：会写明原因（无网络 / 域名解析失败 / 超时 / 服务器返回错误 / 内容异常）

若反复失败，通常是设备网络访问不通，或发布端尚未更新版本信息，可换个时间再试。

## 八、防卸载（可选）

```bash
adb shell dpm set-active-admin com.family.answerlock/.AdminReceiver
```

也可以打开答题锁 → 输密码 → 点「开启防卸载」。想关掉：

```bash
adb shell dpm remove-active-admin com.family.answerlock/.AdminReceiver
```

## 九、常见问题

| 现象 | 处理 |
|---|---|
| 完全不计时 | 无障碍没开；或升级后没「关掉再打开」一次 |
| 时间到了不弹题 | 缺「后台弹出界面」权限，或电池优化没加白名单 |
| 前台一直显示「未识别」 | 打开「使用情况权限」；部分系统限制无障碍读取窗口 |
| 退出应用后无障碍自己关了 | 系统行为。v1.7 已有守护，根治靠「开启自愈」（见第四节） |
| 点「检查更新」没反应 | v1.7 已改为弹窗提示；仍失败时按弹窗里的原因排查 |
| 忘了密码 | 清除应用数据，密码回到 `0000`（设置一并清空） |
| 想彻底卸掉 | 未开防卸载可直接卸载；开过则先执行上面的 `remove-active-admin` 命令 |

**已知软肋**：计时按「当前前台是哪个应用」判断，不检测画面内容，所以孩子用任何 App 干别的也会被计时
（属于误伤，不是漏网）。

## 十一、隐私说明

- 不收集、不上传任何个人信息或使用记录，所有设置与计时数据只存在本机应用私有目录
- 唯一联网行为是「检查更新」：读取一个公开的版本文本文件，用于判断有没有新版本
- 无障碍权限仅用于识别当前前台是哪个应用；使用记录权限仅作为该判定的备用通道
