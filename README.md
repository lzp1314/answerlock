# 答题锁

给孩子用的自律小工具：**看电视 / 玩手机累计满设定时长，自动全屏弹出一道语数英题，答对才能继续**。
答错自动换下一题，直到答对为止。

- 适用：Android 5.0+ 的手机、平板、智能电视（Android TV 及国产电视的 Android 底层）
- 题库：人教版 1–6 年级，数学当场生成不限量，语文 / 英语内置题库；年级、科目、间隔都能自己选
- 计时规则：除系统界面（设置、通知栏、安装器、输入法、锁屏）外，**任何应用在前台都算使用时间**，包括桌面
- 家长密码默认 `0000`，**进去第一件事请改成自己的**

> 各版本改动见 [CHANGELOG.md](CHANGELOG.md)。

## 一、下载与更新

- 最新安装包：仓库根目录的 `answerlock-v1.6.apk`
- **App 每次启动会自动检查更新**，设置页也有「检查更新」按钮
- 发现新版本会弹窗提示，点「去下载」用浏览器拉安装包
- 覆盖安装即可，**不用先卸载**
- `version.json` 是 App 读取的版本配置文件，请勿删除或改名

> 更新提示可能有 1–5 分钟延迟（服务端缓存），稍后再查即可。

## 二、快速开始（三步，缺一步就不生效）

1. 把 APK 传到设备（微信 / QQ 传文件、数据线、U 盘都行），点开安装；提示「未知来源」就允许一次
2. 打开桌面上黄底电视机图标的「答题锁」→ 输密码 `0000` → **先改密码**
3. 点「**无障碍设置**」→ 在列表里找到「答题锁」打开

> ⚠️ **不开无障碍，锁完全不会生效**。这是最常见的问题。

### 手机建议再开两个权限

- 设置页点「**使用情况权限**」→ 找到「答题锁」→ 打开「允许访问使用记录」
- 国产 ROM 还需在「应用管理 → 答题锁」里：
  - 允许「**后台弹出界面**」/ 悬浮窗
  - 电池优化设为「**无限制 / 允许后台活动**」
  - 打开「自启动」

漏了这两项，表现就是「时间到了但什么都不弹」。

### 从旧版升级

升级后请把「答题锁」的无障碍开关 **关掉、退出、再进来打开一次**。
系统会缓存旧的无障碍配置，不重置可能仍然不计时。

## 三、支持哪些设备

| 设备 | 系统 | 无障碍授权方式 |
|---|---|---|
| 安卓手机 / 平板 | Android 5.0+ | 设置页「无障碍设置」直接点 |
| 小米 / 米家电视、索尼电视 | Android / Android TV | 设置页能跳进系统无障碍页 |
| 雷鸟 / TCL、创维 / 酷开、多数海信 | Android 底层 | 通常要电脑 adb 授权（见下） |
| 华为智慧屏 | HarmonyOS | 鸿蒙 2/3 有兼容层，鸿蒙 NEXT 不支持 |

32–100 寸电视的字号会自动适配，不用手动调。

### 电视用 adb 授权（遥控器跳不进无障碍页时）

先在电视「设置 → 关于本机」连点版本号 7 次打开开发者选项，开启 **USB 调试 / 网络 ADB**，记下电视 IP：

```bash
adb connect 192.168.x.x:5555
adb shell settings put secure enabled_accessibility_services com.family.answerlock/com.family.answerlock.DetectService
adb shell settings put secure accessibility_enabled 1
```

验证：

```bash
adb shell settings get secure enabled_accessibility_services
```

返回值里带 `com.family.answerlock/...DetectService` 就成功了。
如果电视上还开着别的无障碍服务，用冒号把原服务拼在前面，否则会被顶掉。

安装也可以用 `adb install -r answerlock-v1.6.apk`。

## 四、家长设置

打开「答题锁」→ 输密码，可设置：

| 设置项 | 说明 |
|---|---|
| 孩子年级 | 1–6 年级，决定题目难度 |
| 出题科目 | 语文 / 数学 / 英语，可多选，至少留一科 |
| 答题间隔 | 5 / 10 / 15 / 20 分钟，默认 10 分钟 |
| 改密码 | 先验证原密码 → 新密码 → 再确认一次，共三步 |
| 防卸载 | 开启后不能直接卸载 |
| 重置计时 | 手动把已看时长归零 |
| 立即测试 | 不用等时长，直接弹一道题看效果 |
| 检查更新 | 手动查新版本 |
| 结束无限观看 | 提前结束家长买断的那一次 |

设置页顶部每 2 秒刷新一次状态，是排查问题的第一现场：

```
监控运行中 · 已看 3:42 / 满 5 分钟出题
前台：tv.danmaku.bili  计时中
通道：事件✓ 窗口✓ 使用记录✓
```

下面还有「诊断 · 最近识别到的前台应用」，列出最近切换过的应用有没有计时。
**看到「前台」在变、显示「计时中」、数字在涨，就是正常。**

## 五、答题界面与家长出口

孩子按返回键、菜单键、设置键、语音键都无效；按 HOME 能回桌面，但 1.2 秒后界面会被拉回来；
关机重启、锁屏解锁也绕不过（已看时长存在本地，30 分钟内算同一次观看）。

底部两个按钮都要输 4 位家长密码：

| 按钮 | 作用 |
|---|---|
| **家长无限观看** | 本次不再计时出题。**关电视 / 锁屏 / 重启立刻作废**，下次亮屏从 0 重新计时 |
| **家长退出** | 直接关掉这一次，并把已看时长归零 |

密码连错 5 次开始冷却，30 秒起逐次翻倍，最长 5 分钟，冷却状态本地保存，重开弹窗也绕不过。

## 六、常见问题

| 现象 | 处理 |
|---|---|
| 完全不计时 | 无障碍没开；或升级后没「关掉再打开」一次 |
| 时间到了不弹题 | 缺「后台弹出界面」权限、电池优化没加白名单 |
| 前台一直「未识别」 | 开「使用情况权限」；部分国产 ROM 会限制无障碍读窗口 |
| 忘了密码 | `adb shell pm clear com.family.answerlock`（手机上也可在「应用管理 → 存储 → 清除数据」）。密码回到 `0000`，但年级、科目等设置会一起清空 |
| 想卸掉 | 没开防卸载可直接卸载；开过则先 `adb shell dpm remove-active-admin com.family.answerlock/.AdminReceiver` |

**已知软肋**：按「当前前台是哪个应用」计时，不检测画面在播什么，所以孩子用任何 App 干别的也会被计时（误伤，不是漏网）。
